First release of Tone3000MPC: NAM A2 amps, pedals and IR cabs, with TONE3000 library browsing, for the Akai Force / MPC OS (ARMv7 VST2 effect).

**Not yet tested on a real Force.** Marked pre-release until it has been run on hardware. Real CPU load of A2 models, the TONE3000 sign-in/search/download path and touch behaviour are unverified.

- Chain of NAM and IR blocks (level, mix, bypass, pre/post EQ), global EQ, noise gate, input calibration, loudness normalisation
- Browse TONE3000 online and download only the captures you choose; everything plays from a local folder
- Unlimited user presets plus 48 factory presets that fill themselves from TONE3000
- Tuner, Q-Links per page, tap-to-MOVE block reordering

Install: copy the zip to the Force and run install.sh (see docs/GUIDE.md). Licence: PolyForm Noncommercial 1.0.0; bundled third-party code keeps its own licences.
